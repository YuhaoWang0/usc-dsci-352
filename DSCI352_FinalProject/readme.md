# DSCI 352 Final Project

This project includes two parts:
1. Telco Customer Churn Prediction
2. Bitcoin Price Forecasting with LSTM

## Folder Structure

- `data/raw/` : original datasets
- `scripts/` : runnable Python scripts
- `outputs/` : generated plots, CSV files, and JSON files
- `report/` : final PDF report

## How to Run

### Telco Churn
Run from the project root:

```bash
python scripts/telco_churn.py
